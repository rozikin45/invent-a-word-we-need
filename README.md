**restigue** — the tiredness that follows a day of doing nothing at all.

Coin one new English word and define it in a single clear line. English has boredom, sluggishness and weariness from effort — but no word for the specific tiredness that comes from resting itself. *Restigue* (rest + the tail of *fatigue*) fills that gap in one reading.

## Run it

```sh
python3 main.py
```

Writes the entry (68 characters) to `/output/entry.txt`. Deterministic: no input, no network, no randomness, no secrets.
